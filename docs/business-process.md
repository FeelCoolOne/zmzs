## 三、数据采集流程

### 3.1 请求拦截与数据采集

**mian.js 中的拦截机制：**

```javascript
// 1. 拦截 XMLHttpRequest
XMLHttpRequest.prototype.open = function() {
  // 记录请求方法和URL
  this._smzs_method = arguments[0];
  // 调用原始方法
  originalOpen.apply(this, arguments);
};

XMLHttpRequest.prototype.send = function() {
  // 记录请求体
  this._smzs_data = arguments[0];
  // 拦截响应
  this.onload = function() {
    // 提取响应数据
    extractData(this);
    // 调用原始回调
    originalOnload.apply(this, arguments);
  };
};

// 2. 拦截 Fetch API
window.fetch = async function() {
  // 执行原始请求
  const response = await originalFetch.apply(this, arguments);
  // 克隆响应以便读取
  const clonedResponse = response.clone();
  // 提取响应数据
  extractData(clonedResponse);
  return response;
};
```

### 4.3 加密算法细节

```javascript
class XorEncryptor {
  constructor() {
    // 生成16字节随机密钥
    this.key = this.generateRandomKey(16);
  }

  generateRandomKey(length) {
    const array = new Uint8Array(length);
    crypto.getRandomValues(array);
    return array;
  }

  encrypt(text) {
    const encoder = new TextEncoder();
    const data = encoder.encode(text);
    const encrypted = new Uint8Array(data.length);
    
    // XOR 加密
    for (let i = 0; i < data.length; i++) {
      encrypted[i] = data[i] ^ this.key[i % this.key.length];
    }
    
    return encrypted;
  }

  getHexKey() {
    return Array.from(this.key)
      .map(b => b.toString(16).padStart(2, '0'))
      .join('');
  }
}
```

## 十、关键业务规则

### 10.1 采集频率限制

| 规则 | 说明 |
|------|------|
| 平台级别限制 | 同一平台 1 小时内只上传一次 |
| 存储位置 | `session:lastCollectTime` |
| 检查逻辑 | `Date.now() - lastTime < 3600 * 1000` |

### 10.2 文件上传限制

| 规则 | 说明 |
|------|------|
| 大小限制 | 20MB (20971520 bytes) |
| 超限处理 | 拒绝上传，抛出错误 |
| 上传方式 | FormData，POST 请求 |

### 10.3 平台支持列表

| 平台 | 域名 | 特殊功能 |
|------|------|----------|
| 小红书 | xiaohongshu.com | vendor-dynamic 注入 |
| 小红书蒲公英 | pgy.xiaohongshu.com | 白名单验证 |
