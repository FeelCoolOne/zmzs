# 社媒助手 - 侧边栏与设置页功能梳理

## 一、侧边栏 (Side Panel) 功能

侧边栏是扩展的主要操作界面，通过 `sidepanel.html` 加载，是一个 React 单页应用。

### 1. 路由结构

```
侧边栏路由 (yG 数组定义)
├── / (index) - 首页/批量导出达人数据
├── /batch-collect - 批量采集
│   ├── /blogger - 批量导出达人数据
│   └── /note - 批量导出笔记数据
├── /hidden-collect - 隐藏采集
│   ├── /search-invite - 搜索邀约
│   ├── /search-note - 搜索笔记
│   └── /search-blogger - 搜索博主
└── /other - 其他工具
    ├── /batch-invite - 批量邀约
    ├── /batch-order - 批量下单
    └── /id-transform - ID转换工具
```

### 2. 核心功能模块

#### 2.1 批量导出达人数据 (`/`)
- **功能描述**: 批量导出社交媒体达人/博主数据
- **采集方式**:
  - 通过达人链接采集
  - 通过关键词搜索采集
- **配置项**:
  - 达人链接输入（支持批量粘贴）
  - 关键词输入
  - 采集数量限制 (`limit`)
  - 导出格式选择

#### 2.2 批量导出笔记数据 (`/batch-collect/note`)
- **功能描述**: 批量导出笔记/内容数据
- **输入方式**: 笔记链接批量输入
- **导出字段**: 笔记标题、内容、点赞数、评论数等

#### 2.3 隐藏采集功能 (`/hidden-collect/*`)
- **搜索邀约** (`search-invite`): 基于搜索结果的批量邀约
- **搜索笔记** (`search-note`): 基于搜索的笔记采集
- **搜索博主** (`search-blogger`): 基于搜索的博主采集

#### 2.4 蒲公英平台工具 (`/other/*`)
- **批量邀约** (`batch-invite`): 批量向博主发送合作邀约
  - 支持输入博主ID列表
  - 自动填充邀约信息
  - 批量发送邀约

- **批量下单** (`batch-order`): 批量进行笔记合作下单
  - 加购功能
  - 自动跳转下单页面

- **ID转换工具** (`id-transform`): 笔记ID转为有效笔记链接
  - 支持批量转换
  - 24位ID格式验证

#### 2.5 链接转换工具
- **短链解析**: 短链接转长链接
- **长链转短链**: 长链接转短链接
- **批量转换**: 支持多个链接批量处理

### 3. 侧边栏UI组件

- **Card 卡片布局**: 功能模块分组展示
- **Form 表单**: 数据输入和配置
- **Table 表格**: 数据展示和结果列表
- **Button 按钮**: 操作触发
- **Modal/Drawer**: 弹窗和抽屉式交互
- **Progress 进度条**: 批量任务进度展示
- **Message/Notification**: 操作反馈提示

## 二、设置页 (Options Page) 功能

设置页通过 `options.html` 加载，是扩展的配置中心。

### 1. 导航菜单结构

```
设置页左侧导航菜单
├── 通用设置 (/)
├── 网页功能 (/feature)
├── 素材下载 (/download)
├── 数据上报 (/data-reporting)
├── ──────────────── (divider)
├── 帮助中心 (外链)
├── 联系我们 (外链)
├── 意见反馈 (外链)
└── 更新日志 (外链)
```

### 2. 各设置项详情

#### 2.1 通用设置 (`/`)
- **账号管理**: 各平台账号登录状态查看
  - 抖音账号
  - 小红书账号
  - 蒲公英账号
  - 快手账号
  - TikTok账号

- **基础配置**:
  - 设备ID配置
  - 采集参数设置
  - 默认导出格式

#### 2.2 网页功能 (`/feature`)
- **功能开关**: 各平台网页增强功能的启用/禁用
- **自动采集设置**: 页面加载时自动采集配置
- **界面优化选项**: 网页界面优化相关设置

#### 2.3 素材下载 (`/download`)
- **下载配置**:
  - 并发下载数设置 (`maxConcurrentDownloads`)
  - 下载路径设置
  - 文件命名规则
  
- **下载管理**:
  - 下载任务列表
  - 下载进度查看
  - 下载历史记录

#### 2.4 数据上报 (`/data-reporting`)
- **上报规则配置**: 配置数据上报接口规则
- **飞书集成**: 飞书多维表格上报配置
  - 飞书应用ID
  - 表格配置
  - 字段映射设置
  
- **上报历史**: 查看数据上报记录

### 3. 设置页UI组件

- **Menu 侧边导航菜单**: 左侧固定导航
- **Form 表单**: 配置项编辑
- **Input/InputNumber**: 文本和数字输入
- **Select 下拉选择**: 选项配置
- **Switch 开关**: 功能启用/禁用
- **Button 按钮**: 保存、重置操作

## 三、功能对比表

| 功能维度 | 侧边栏 (Side Panel) | 设置页 (Options Page) |
|---------|--------------------|----------------------|
| **主要用途** | 日常操作、数据采集、批量任务 | 系统配置、账号管理、功能开关 |
| **使用频率** | 高频使用 | 低频使用（一次性配置） |
| **界面布局** | 紧凑、功能导向 | 宽松、配置导向 |
| **核心功能** | 批量采集、导出、邀约、下单 | 账号配置、下载设置、上报配置 |
| **数据展示** | 表格、列表、进度 | 表单、开关、选项 |
| **交互方式** | 即时操作、批量处理 | 配置保存、参数调整 |
| **打开方式** | 点击扩展图标或侧边栏按钮 | 右键扩展图标→选项 |

## 六、使用场景建议

### 使用侧边栏的场景：
1. 需要批量采集达人/笔记数据
2. 进行蒲公英平台的批量邀约/下单操作
3. 查看下载任务进度
4. 进行链接转换等快捷操作

### 使用设置页的场景：
1. 首次安装扩展时的初始化配置
2. 配置各平台账号信息
3. 调整下载并发数和路径
4. 配置数据上报规则
5. 开启/关闭网页增强功能
