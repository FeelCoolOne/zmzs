# 飞书多维表格配置指南

## 概述

本扩展支持将小红书采集的数据直接同步到飞书多维表格，方便团队协作和数据分析。

## 配置步骤

### 第一步：创建飞书自建应用

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 登录后点击「开发者后台」
3. 点击「创建企业自建应用」
4. 填写应用信息：
   - 应用名称：小红书采集助手
   - 应用描述：用于同步小红书数据到多维表格
   - 应用图标：可选

### 第二步：获取 App ID 和 App Secret

1. 进入创建好的应用详情页
2. 在「凭证与基础信息」页面找到：
   - **App ID**（应用 ID）：格式如 `cli_xxxxxxxxxxxx`
   - **App Secret**（应用密钥）：点击显示按钮查看

3. **保存这两个值**，后续配置需要使用

### 第三步：创建多维表格

1. 打开 [飞书多维表格](https://www.feishu.cn/product/base)
2. 创建一个新的多维表格
3. 设置表格字段，建议包含以下列：

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 笔记ID | 文本 | 小红书笔记的唯一标识 |
| 笔记标题 | 文本 | 笔记的标题 |
| 笔记内容 | 文本 | 笔记的正文内容 |
| 点赞数 | 数字 | 笔记获得的点赞数量 |
| 收藏数 | 数字 | 笔记获得的收藏数量 |
| 评论数 | 数字 | 笔记的评论数量 |
| 分享数 | 数字 | 笔记的分享数量 |
| 笔记链接 | 超链接 | 笔记的URL地址 |
| 博主ID | 文本 | 博主的唯一标识 |
| 博主昵称 | 文本 | 博主的昵称 |
| 粉丝数 | 数字 | 博主的粉丝数量 |
| 关注数 | 数字 | 博主关注的用户数量 |
| 获赞与收藏 | 数字 | 博主获得的总点赞和收藏数 |
| 博主链接 | 超链接 | 博主主页的URL地址 |
| 采集时间 | 日期时间 | 数据采集的时间 |
| 平台 | 文本 | 数据来源平台 |

### 第四步：获取多维表格 Token 和 Table ID

1. 打开你创建的多维表格
2. 查看浏览器地址栏，URL 格式如下：
   ```
   https://www.feishu.cn/base/Bascnxxxxxxxxxxxxx?table=tblxxxxxxxxxxxxx
   ```

3. **提取参数**：
   - **多维表格 Token**（App Token）：`Bascnxxxxxxxxxxxxx` 部分
   - **表格 ID**（Table ID）：`tblxxxxxxxxxxxxx` 部分

### 第五步：添加应用到多维表格

1. 在多维表格页面，点击右上角的「...」菜单
2. 选择「添加文档应用」
3. 搜索你创建的应用名称「小红书采集助手」
4. 点击添加，并授予编辑权限

### 第六步：在扩展中配置飞书

#### 方法一：通过悬浮按钮配置

1. 访问小红书笔记页面
2. 点击右侧悬浮按钮区域的 🚀 **同步飞书** 按钮
3. 如果是首次使用，会自动弹出配置窗口
4. 填写以下信息：
   - **App ID**：从第二步获取
   - **App Secret**：从第二步获取
   - **多维表格 Token**：从第四步获取
   - **表格 ID**：从第四步获取
5. 点击「保存配置」

#### 方法二：通过侧边栏配置

1. 点击扩展图标打开侧边栏
2. 点击工具栏中的 🚀 **飞书配置** 按钮
3. 在弹出的配置窗口中填写信息
4. 可以点击「测试连接」验证配置是否正确
5. 点击「保存配置」

## 使用飞书同步功能

### 同步单条数据

1. 打开任意小红书笔记页面
2. 点击右侧悬浮按钮的 🚀 **同步飞书**
3. 等待同步完成，会显示成功提示
4. 数据会自动添加到飞书多维表格中

### 同步的数据内容

每次同步会包含以下数据：

**当前笔记数据**：
- 笔记的基本信息（ID、标题、内容）
- 互动数据（点赞、收藏、评论、分享数）
- 笔记链接和采集时间

**当前用户数据**（如果是博主页面）：
- 博主的基本信息（ID、昵称）
- 粉丝和关注数据
- 获赞与收藏总数
- 博主主页链接

## 常见问题

### Q1: 提示"未找到指定的多维表格"

**错误码**：91402

**解决方法**：
- 检查多维表格 Token 是否正确
- 确认从 URL 中复制的 Token 完整无误
- 确保多维表格没有被删除

### Q2: 提示"没有权限访问此表格"

**错误码**：91403

**解决方法**：
- 确保已将应用添加到多维表格（第五步）
- 检查应用是否被授予编辑权限
- 尝试重新添加应用到多维表格

### Q3: 提示"访问凭证无效"

**错误码**：99991663

**解决方法**：
- 检查 App ID 和 App Secret 是否正确
- 确认应用没有被停用或删除
- 重新复制 App Secret（注意区分大小写）

### Q4: 同步成功但数据没有显示

**解决方法**：
- 刷新多维表格页面
- 检查表格字段名称是否与同步字段匹配
- 查看多维表格的筛选条件是否隐藏了新数据

### Q5: 如何修改已保存的配置？

**解决方法**：
- 点击侧边栏的 🚀 **飞书配置** 按钮
- 在弹窗中修改配置信息
- 点击「保存配置」覆盖原有配置

## 安全提示

1. **保护 App Secret**：不要分享给他人，相当于应用的密码
2. **定期检查权限**：定期查看哪些应用可以访问你的多维表格
3. **使用专用表格**：建议为数据采集创建专门的多维表格
4. **备份重要数据**：定期导出飞书表格数据作为备份

## 高级配置

### 自定义字段映射

如果你需要同步到不同的字段名称，可以修改 `content.js` 中的 `prepareSyncData` 方法：

```javascript
prepareSyncData() {
  const records = [];
  
  if (this.currentNoteData) {
    const note = this.currentNoteData;
    records.push({
      fields: {
        '你的自定义字段名': note.title,
        // ... 其他字段
      }
    });
  }
  
  return records;
}
```

### 批量同步数据

目前支持单条笔记同步，如需批量同步侧边栏中的所有数据，可以在 sidepanel.js 中添加批量同步功能。

## 技术支持

如遇到问题，请检查：
1. 飞书应用是否正常运行
2. 多维表格权限是否正确设置
3. 网络连接是否正常
4. 扩展是否有存储权限
