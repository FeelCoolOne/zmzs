# Icons 目录

此目录需要放置以下尺寸的 PNG 图标文件：

- `icon16.png` - 16x16 像素，用于工具栏
- `icon32.png` - 32x32 像素，用于工具栏（高分屏）
- `icon48.png` - 48x48 像素，用于扩展管理页面
- `icon128.png` - 128x128 像素，用于 Chrome Web Store

## 图标设计建议

1. 使用小红书品牌色（#FF2442）作为主色调
2. 图标内容可以包含：
   - 📕 书本图标
   - 🔍 搜索/采集图标
   - 或自定义设计

## 生成工具

可以使用以下在线工具生成图标：
- [favicon.io](https://favicon.io/)
- [Canva](https://www.canva.com/)
- [Figma](https://www.figma.com/)

## 注意事项

- 图标需要是 PNG 格式
- 背景建议透明
- 保持简洁，在小尺寸下也能清晰识别
