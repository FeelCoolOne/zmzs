# 快速开始指南

## 安装扩展

### 步骤 1：准备文件

确保 `offline-version` 文件夹包含以下文件：

```
offline-version/
├── manifest.json
├── background.js
├── sidepanel.html
├── options.html
├── lib/indexeddb.js
├── scripts/sidepanel.js
├── scripts/options.js
├── styles/sidepanel.css
├── styles/options.css
├── content-scripts/content.js
├── content-scripts/main.js
├── content-scripts/inject-xiaohongshu.js
├── content-scripts/inject-douyin.js
├── content-scripts/inject-kuaishou.js
├── content-scripts/inject-tiktok.js
├── icon/icon.svg
├── _locales/zh_CN/messages.json
└── README.md
```

### 步骤 2：加载扩展

1. 打开 Chrome 浏览器
2. 在地址栏输入：`chrome://extensions/`
3. 打开右上角的 **"开发者模式"** 开关
4. 点击左上角的 **"加载已解压的扩展程序"** 按钮
5. 选择 `offline-version` 文件夹
6. 扩展安装成功！

## 基本使用

### 打开侧边栏

有两种方式打开侧边栏：

1. **点击扩展图标**：在浏览器工具栏点击社媒助手图标
2. **使用快捷键**：按 `Alt + C`

### 采集数据

#### 方法 1：自动采集

1. 访问支持的平台（如小红书、抖音）
2. 正常浏览页面
3. 扩展会自动拦截 API 请求并采集数据
4. 在侧边栏查看采集到的数据

#### 方法 2：手动采集

1. 打开侧边栏
2. 点击 **"采集当前页面"** 按钮
3. 扩展会尝试采集当前页面的数据

### 查看数据

1. 打开侧边栏
2. 查看 **"最近采集"** 区域
3. 显示最近 5 条采集的数据
4. 每条数据显示：
   - 平台图标
   - 数据标题
   - 采集时间

### 导出数据

1. 打开侧边栏
2. 点击 **"导出数据"** 按钮
3. 选择导出格式：
   - `1` - JSON 格式
   - `2` - CSV 格式
   - `3` - XLSX 格式
4. 浏览器会弹出下载对话框
5. 选择保存位置并下载

### 清空数据

1. 打开侧边栏
2. 点击 **"清空数据"** 按钮
3. 确认清空操作
4. 所有数据将被删除（不可恢复）

## 设置页面

### 打开设置

1. 打开侧边栏
2. 点击右上角的 **设置图标**（齿轮）
3. 或在扩展管理页面点击"选项"

### 基本设置

- **自动导出**：采集后自动导出数据
- **导出格式**：选择默认的导出格式（JSON/CSV/XLSX）
- **下载路径**：设置媒体文件的下载路径
- **最大文件大小**：限制下载的媒体文件大小（MB）

### 采集设置

- **采集模式**：
  - 手动采集：需要手动触发
  - 自动采集：自动采集所有数据
  - 混合模式：结合两者
- **采集间隔**：自动采集的时间间隔（秒）

### 数据管理

- 查看统计数据（已采集、媒体文件、下载次数、导出次数）
- 导出所有数据
- 清空所有数据

## 常见问题

### Q: 扩展无法加载？

A: 请检查：
1. 是否开启了开发者模式
2. manifest.json 文件是否存在且格式正确
3. 所有必需的文件是否都在文件夹中

### Q: 数据没有自动采集？

A: 请检查：
1. 是否在支持的平台页面上
2. 浏览器控制台是否有错误信息
3. 刷新页面重试

### Q: 导出失败？

A: 请检查：
1. 是否有采集的数据
2. 浏览器是否允许下载
3. 磁盘空间是否充足

### Q: 如何查看采集的原始数据？

A: 导出为 JSON 格式，然后用文本编辑器或 JSON 查看器打开

### Q: 数据存储在哪里？

A: 数据存储在浏览器的 IndexedDB 中，完全本地化，不会上传到任何服务器

### Q: 如何备份数据？

A: 导出所有数据为 JSON 格式，保存到安全的位置

### Q: 如何恢复数据？

A: 目前不支持数据恢复功能，建议定期导出备份
